# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project uses [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-10-18

### Added

- Published on npm: `npm install csv2json-mini`, or run it with `npx csv2json-mini`.
- `require("csv2json-mini")` works on Node 22.12 or newer.

### Changed

- The repository is public, and CI runs on Linux, Windows and macOS again.

## [0.1.1] - 2026-10-18

### Changed

### Added
